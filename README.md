# Retrain or teach? How AI learns after it's built. Does the language matter?

Lab-meeting talk (10 minutes, MHM Lab, 23 Oct 2026) by Nitin Sharma on three pieces of work: activation steering, NewsCPT (continued pretraining on news) and a multilingual study of how new knowledge transfers across languages.

**To continue this project in a new session, read [`HANDOFF.md`](HANDOFF.md).**

- `slides/Lab_presentation_Nitin_23rd_Oct_2026.pptx`: the deck (18 slides, speaker notes included)
- `slides/build_pptx.js`: generates the deck (`npm install pptxgenjs react react-dom react-icons sharp jszip`)
- `slides/plot_summary_figure.py`, `slides/summary_part2.png`: the Part 2 summary figure
- `web_deck/`: the same deck as HTML slides for the claude.ai Slides artifact
- `docs/`: decision log, slide outline, every number with its source, the user's messages and notes
- `papers/`, `reference/`: paper notes and reference material (see the READMEs there)

Now the second situation. Steering only surfaces what the model already read. But every model finished school at some point, for the ones we use, around the end of 2023. New drugs, new guidelines, yesterday's news: never saw them. For that, the model has to actually learn, and that means training. And training, as we saw, costs: money and forgetting. So two questions: can we make it cheap, and can we minimise the forgetting?

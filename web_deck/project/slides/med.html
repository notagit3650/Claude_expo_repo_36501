Why does any of this matter? Start with the clinic. There are amazing models out there, but doctors hesitate to use them: in the latest AMA survey, 86% of physicians say they need data-privacy assurances before adopting AI, because the big models run on someone else's cluster and the patient data leaves the building. So what we want is a small model that runs locally and still understands medicine. The question: can we make a model understand a domain without retraining it?
